作品目標：

本作品以兩組多變量分群資料為例，運用主成分分析進行降維，同時維持良好的群組判別能力。分析內容涵蓋資料特徵的解讀、各式統計圖形的輔助呈現、主成分的選取依據，以及主成分負荷量所反映的變數結構等面向，逐步展開探討。透過這一系列分析，可更清楚理解主成分分析在機器學習中作為特徵擷取方法的角色，不僅能降低資料維度以提升運算效率，也可能增進分群表現。

1：Quality of Life Index by City 2026

  • 內容：2026 年世界城市生活品質指標
  • 來源：NUMBEO https://www.numbeo.com/quality-of-life/rankings.jsp?title=2026
  • 數量：304 個城市的指標數字
  • 特徵：8 個與城市相關的面向指標
  • 群組標籤：無。但可依生活品質總分（Quality of Life Index）分為若干個群組，譬如依總分大小分為 3 或 4 群（按實際分布），並給予群組標籤。假設分 3 個群組，則給予 H, M, L 分別代表高品質、中品質與低品質城市。

資料讀取與群組標籤設定：

首先讀入 NUMBEO 的城市生活品質資料，取出其八個指標作為特徵，並依照生活品質總分（Quality of Life Index）將城市分為高（H）、中（M）、低（L）三群。

In [2]:
df = pd.read_excel("2026_city_quality.xlsx")

score = df['Quality of Life Index']  # 以生活品質總分劃分為高中低三群

q1, q2 = score.quantile([1/3, 2/3])  #  依[1/3, 2/3]分位數劃分
def label_group(s):
    if s >= q2:
        return 'H'
    elif s >= q1:
        return 'M'
    else:
        return 'L'

df['Group'] = score.apply(label_group)

features = ['Purchasing Power Index',
            'Safety Index',
            'Health Care Index',
            'Cost of Living Index',
            'Property Price to Income Ratio',
            'Traffic Commute Time Index',
            'Pollution Index',
            'Climate Index']

X = df[features].values
groups = df['Group'].values

標準化與主成分分析（PCA）：

先對八個特徵做標準化處理，使其均值為 0、變異數為 1，以避免尺度影響 PCA。再進行主成分分析（PCA），觀察各個主成分的解釋變異比例與累積解釋變異，作為選取主成分個數的依據。

In [3]:
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# Standardize
scaler = StandardScaler()
X_std = scaler.fit_transform(X)

pca_full = PCA()
X_pca_full = pca_full.fit_transform(X_std)

explained_var = pca_full.explained_variance_ratio_
cum_explained_var = np.cumsum(explained_var)

print("各主成分解釋變異比例:", explained_var)
print("累積解釋變異比例:", cum_explained_var)
plt.figure(figsize=(6,4))
plt.plot(range(1, len(explained_var)+1), cum_explained_var, marker='o')
plt.xlabel('Principal Components')
plt.ylabel('Cumulate explained variance')
plt.ylim(0, 1.05)
plt.grid(True)
plt.show()

由圖可以清楚地看見，在 PC1 中各變數負荷量的特徵如下：

  • Pollution Index（+0.47）：負荷量為正且最大，表示 PC1 高的城市污染較嚴重
  • Traffic Commute Time Index、Property Price to Income Ratio（約 +0.33）：負荷量為正，代表通勤時間較長、房價所得比較高
  • Purchasing Power Index（−0.46）、Cost of Living Index（−0.44）：負荷量為負，表示 PC1 高的城市購買力較低

因此，PC1 數值愈高代表城市整體生活條件愈差（高污染、低購買力）；PC1 數值愈低則代表城市生活品質愈佳，可詮釋為反向的生活品質綜合指標。

在 PC1–PC2 平面上的散布圖中，可觀察到三群城市的分布具有明顯的排序關係：

  • H 群（紅色）：多集中在 PC1 較低的區域（低污染、高購買力）
  • M 群（橘色）：大致分布在中間位置
  • L 群（藍色）：主要出現在 PC1 較高的一側（高污染、低購買力）

結合前述主成分負荷量，PC1 數值愈高代表城市生活條件愈差，因此三個群組在 PC1 上形成 H → M → L 的有序分離（由左至右品質遞減）。此結果顯示，在僅保留前兩個主成分（累積解釋約 58.1% 變異）的情況下，PCA 仍能相當良好地保留原本依生活品質總分劃分之群組結構與判別能力。

資料集共有 569 筆、30 個特徵，兩群分布如下：

標準化與主成分分析（PCA）：

對 30 個特徵進行標準化處理，使各特徵的均值為 0、變異數為 1，以避免量綱差異影響 PCA 結果。接著進行完整 PCA，觀察各主成分的解釋變異比例與累積解釋變異，作為選取主成分個數的依據。

from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

pca_full = PCA()

explained_var = pca_full.explained_variance_ratio_
cum_var = np.cumsum(explained_var)

plt.figure(figsize=(8, 4))
plt.plot(range(1, len(explained_var)+1), cum_var, marker='o')
plt.axhline(y=0.9, color='r', linestyle='--', label='90%')
plt.xlabel('Number of Principal Components')
plt.ylabel('Cumulative Explained Variance')
plt.title('PCA Cumulative Explained Variance - Breast Cancer')
plt.legend()
plt.grid(True)
plt.show()

從累積解釋變異圖可知，30 個特徵之間存在高度的線性相關結構：

  • PC1：解釋約 44.3% 的總變異
  • PC2：解釋約 18.9% 的總變異
  • 前兩個主成分累積解釋約 63.2%，約 7 個主成分即可達 90%

相較於第一題（8 個特徵），第二題的 30 個特徵維度雖然高得多，但前幾個主成分仍能捕捉大部分的資訊結構，顯示這批細胞核量測指標之間具有強烈的共變異性，適合以 PCA 降維。後續群組分析仍以 PC1 與 PC2 為主要觀察平面。

總結論：

本作品以兩組不同性質的資料集，驗證了主成分分析（PCA）在群組資料降維上的有效性：

第一題（城市生活品質，8 個特徵，3 群）

  • 前兩個主成分累積解釋約 58.1% 的總變異，前四個主成分達 81.3%
  • PC1 為反向的生活品質綜合指標（高 PC1 = 高污染、低購買力）；PC2 反映安全感與氣候舒適度的對比
  • 在 PC1–PC2 平面上，H、M、L 三群城市呈現 H → M → L 的有序分離

第二題（乳癌腫瘤，30 個特徵，2 群）

  • 30 個特徵間存在高度線性相關，前兩個主成分累積即可解釋約 63% 的總變異，約 7 個主成分可達 90%
  • PC1 主要反映腫瘤的整體大小與惡性程度（尺寸、凹陷程度等）；PC2 反映紋理複雜度
  • 在 PC1–PC2 平面上，惡性與良性腫瘤在 PC1 方向上具有清晰的群組分離

兩組分析均顯示，PCA 在大幅降低特徵維度的同時，仍能有效保留原始群組的判別結構，驗證其作為機器學習特徵擷取工具的實用性。
